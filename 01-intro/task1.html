Практична робота: Перша програма на JavaScript

Тема 1. Проєкт «Створення профілю героя RPG гри»

Інструкція: Виконуйте завдання послідовно, рядок за рядком у своєму редакторі коду. Всі змінні та дані зберігаються для наступних етапів програми.

Способи підключення скриптів

Де і як працює JavaScript у браузері

Завдання 1.1: Внутрішній скрипт

Створіть файл index.html. У тезі <head> додайте тег <script> та напишіть у ньому команду для виводу повідомлення в консоль: console.log("Запуск системи...");. Перевірте роботу, відкривши консоль розробника (F12).

Завдання 1.2: Зовнішній скрипт (Рекомендовано)

Створіть поруч файл game.js. У index.html підключіть його за допомогою тегу <script src="game.js" defer></script>. Атрибут defer гарантує, що скрипт виконається лише після завантаження всього HTML. Всі подальші завдання виконуйте у файлі game.js.

Console
▶ "Запуск системи..."
▶ "Запуск зовнішнього скрипта..."

Діалог з користувачем

alert, prompt, confirm та console

Завдання 2.1: Вітання та попередження

Викличте вікно alert("Вітаємо у грі 'Таємниці коду'!"). Одразу після цього виведіть у консоль попередження за допомогою console.warn("Початок збору даних гравця").

Завдання 2.2: Отримання відповідей

Використайте prompt(), щоб запитати: "Введіть ім'я вашого героя:". На наступному рядку використайте confirm() із питанням "Увімкнути режим 'Хардкор' (1 життя)?". Поки що просто викличте ці функції, щоб побачити вікна.

Вітаємо у грі 'Таємниці коду'!

Змінні

Оголошення констант та змінних величин

Завдання 3.1: Збереження введення користувача

Модифікуйте код з попереднього кроку. Створіть змінну let heroName і присвойте їй результат prompt. Далі створіть константу const isHardcore і присвойте їй результат confirm.

Завдання 3.2: Базові характеристики

Оголосіть змінні для початкових ігрових характеристик. Створіть змінну (let) level зі значенням 1, та змінну health зі значенням 100. Створіть константу (const) maxInventorySize зі значенням 50.

Підказка здоров'я та рівень будуть змінюватися під час гри, тому це let, а розмір інвентарю фіксований — тому const.

Типи даних

String, Number, Boolean, Null, Undefined

Завдання 4.1: Спеціальні типи даних

Створіть змінну let currentWeapon = null; (символізує, що зброї поки що немає, але контейнер готовий). Створіть змінну let magicSkill; без присвоєння значення (вона автоматично стане undefined).

Завдання 4.2: Перевірка типів (typeof)

За допомогою оператора typeof виведіть у консоль типи змінних: heroName, level, isHardcore, currentWeapon та magicSkill.

Console
▶ "string" // typeof heroName
▶ "number" // typeof level
▶ "boolean" // typeof isHardcore
▶ "object" // typeof currentWeapon (особливість JS)
▶ "undefined" // typeof magicSkill

Операції зі змінними

Арифметичні дії та конкатенація рядків

Завдання 5.1: Математичні події

Ваш персонаж знайшов артефакт! Збільште змінну level на 1, використовуючи інкремент (++). Також персонаж наступив на пастку — зменште health на 15 одиниць, використовуючи оператор комбінованого присвоєння (-=).

Завдання 5.2: Рядкові операції

Створіть змінну let title = " Шукач пригод";. Створіть нову змінну fullHeroName, яка буде результатом додавання (конкатенації) змінних heroName та title.

Оператори порівняння

Логічні вирази та строга рівність

Завдання 6.1: Запит віку та порівняння

Використайте prompt, щоб запитати "Вкажіть вік гравця:", і збережіть у змінну playerAge. Далі створіть змінну let isAdult = playerAge >= 18;. (Результатом буде true або false).

Завдання 6.2: Строга нерівність

Перевірте, чи гравець не залишив поле імені порожнім. Створіть змінну let isValidName = heroName !== "";. Ми використовуємо строго не дорівнює (!==).

Console (Якщо вік 16, а ім'я введено)
▶ false // isAdult
▶ true // isValidName

Умови (if-else)

Розгалуження логіки програми

Завдання 7.1: Базова умова

Напишіть умову if: якщо isValidName дорівнює false (або !isValidName), то виведіть alert("Ім'я не вказано! Призначено стандартне.") та змініть значення fullHeroName на "Невідомий мандрівник".

Завдання 7.2: Складна умова (if - else if - else)

Налаштуємо стартове здоров'я в залежності від віку та режиму.
- Якщо isHardcore дорівнює true, встановіть health = 1.
- Інакше, якщо isAdult дорівнює false (!isAdult), встановіть health = 200 (спрощений режим для дітей).
- В іншому випадку (else), встановіть health = 100.

Шаблони запису та вирази

Зворотні лапки (`) та інтерполяція ${}

Завдання 8.1: Текстовий шаблон

Згенеруйте фінальне текстове повідомлення у консоль. Замість конкатенації плюсами, використайте зворотні лапки (backticks).
Напишіть: console.log(`Персонаж ${fullHeroName} створений! Рівень: ${level}. HP: ${health}`);

Завдання 8.2: HTML шаблон

Створіть змінну let htmlCard. Використовуючи багаторядкові зворотні лапки, напишіть всередині неї структуру HTML-картки, підставивши туди змінні fullHeroName, level та health (див. код нижче).

let htmlCard = `
  <div class="card">
    <h2>🗡️ ${fullHeroName}</h2>
    <p>Статус: ${isHardcore ? "Хардкор" : "Стандарт"}</p>
    <ul>
      <li>Рівень: ${level}</li>
      <li>Здоров'я: ${health} HP</li>
    </ul>
  </div>
`;

Виведення на сторінку (DOM)

document.getElementById та document.body.innerHTML

Завдання 9.1: Вставка в конкретний елемент

У вашому файлі index.html (всередині тегу <body>) створіть порожній блок: <div id="app"></div>. У файлі скрипта використайте document.getElementById("app").innerHTML = htmlCard;, щоб помістити створену картку гравця на сторінку.

Завдання 9.2: Додавання в кінець body

Тепер за допомогою document.body.innerHTML += ... додайте в самий кінець сторінки (не видаляючи попередній контент завдяки оператору +=) невеличкий футер: `<footer>© 2026 Створено в рамках курсу</footer>`.
