Знайомство з багатовимірним масивом

Ваш масив movies містить інші масиви всередині себе. Давайте перевіримо, як з ним працювати.

Кроки виконання:

  • Виведіть у консоль загальну кількість фільмів (довжину головного масиву).
  • Виведіть у консоль назву першого фільму.
  • Напишіть вкладений цикл for (цикл у циклі). Перший цикл перебирає фільми, другий — характеристики кожного фільму.
  • Всередині другого циклу виведіть інформацію у консоль. Додайте умову if, щоб не виводити опис фільму (індекс 2), оскільки він занадто довгий.
💡 Підказка: Щоб отримати доступ до елемента двовимірного масиву, використовуйте два індекси поспіль: масив[рядок][стовпець]. Наприклад, movies[0][3] — це оцінка першого фільму.

Цикл while + switch: Вибір теми

Зробимо так, щоб користувач міг обрати тему оформлення (темну або світлу), і будемо запитувати його, поки він не введе правильне значення.

Кроки виконання:

  • Створіть змінну selectedStyle зі значенням за замовчуванням 'dark'.
  • Створіть логічну змінну notAnswered зі значенням true.
  • Створіть цикл while, який працюватиме, поки notAnswered є true.
  • Всередині циклу запитайте користувача через prompt: "Виберіть тему: темна чи світла".
  • Якщо користувач натисне "Скасувати" (значення null), зупиніть цикл.
  • Створіть конструкцію switch, яка перевіряє відповідь.
  • Якщо введено "темна" — змініть selectedStyle на 'dark' і зупиніть повторення циклу. Якщо "світла" — на 'light' і також зупиніть.
  • Для інших випадків (default) виводьте alert, що варіант неправильний (цикл піде на нове коло).
💡 Підказка: Користувач може ввести слово з пробілами або великими літерами. Щоб switch працював без помилок, застосуйте до відповіді методи очищення: відповідь.trim().toLowerCase(). Щоб достроково вийти з циклу при null, використайте команду break.

Обчислення середньої оцінки

Використаємо цикл while для підрахунку середнього балу всіх фільмів.

Кроки виконання:

  • Створіть змінну sum (для накопичення суми) та змінну-лічильник k. Обидві дорівнюють 0.
  • Напишіть цикл while, який перебирає всі елементи масиву movies.
  • На кожній ітерації додавайте оцінку поточного фільму до змінної sum.
  • Не забудьте збільшувати лічильник k на 1 всередині циклу!
  • Після циклу створіть змінну average та обчисліть середню оцінку (сума поділена на кількість фільмів).
💡 Підказка: Щоб результат виглядав гарно (наприклад, 7.1, а не 7.140000001), використайте метод .toFixed(1) для результату ділення. Згадайте, під яким індексом знаходиться оцінка у внутрішньому масиві.

Фільтрація: найкращі фільми

Знайдемо фільми, які мають оцінку 7 або вище, і збережемо їхні назви в окремий масив.

Кроки виконання:

  • Створіть новий порожній масив bestMovies.
  • Використайте цикл for для проходження по масиву movies.
  • Всередині циклу напишіть умову if: якщо оцінка фільму більше або дорівнює 7...
  • ...тоді додайте назву цього фільму в масив bestMovies.
💡 Підказка: Щоб додати новий елемент у кінець існуючого масиву, використовується метод назваМасиву.push(новеЗначення).
5

Формування сторінки (Виведення у DOM)

Тепер найцікавіше — перетворимо наші дані на реальний HTML-код і покажемо його на екрані!

Кроки виконання:

  • Створіть текстову змінну header. Запишіть у неї стартовий HTML-код: тег <header> з класом обраної теми (selectedStyle), заголовок <h1> та відкриваючий тег списку <ul class="moviesList">.
  • Пройдіться циклом for по фільмах і додайте (через +=) до змінної header елементи списку <li>. Кожен пункт має містити картинку та посилання з назвою фільму.
  • Закрийте теги списку та хедера.
  • Аналогічно створіть змінну description для секції з описами (використовуйте теги <section>, <h3> для назви, <p> для опису та оцінки). Пройдіться циклом, щоб згенерувати описи для всіх фільмів.
  • В кінці секції з описами додайте параграф зі статистикою: виведіть змінну average та масив bestMovies.
  • Об'єднайте header та description і запишіть результат у document.body.innerHTML.
💡 Підказка: Використовуйте шаблонні рядки (зворотні апострофи `), щоб зручно підставляти змінні у HTML-код через ${}. Щоб гарно вивести масив з найкращими фільмами через кому, використайте метод bestMovies.join(', ').
